# Sistema de Gestión de Biblioteca

Sistema completo de gestión de biblioteca con **Backend en Java**, **Base de Datos SQLite** e **Interfaz Web moderna ( Vite + Tailwind)**.

---

## 🚀 Cómo Iniciar el Sistema (1 solo clic)

Simplemente haz **doble clic** en:
- **`INICIAR_SISTEMA.bat`** (en la raíz del proyecto)

El sistema automáticamente:
1. Iniciará el servidor de Biblioteca (Java Core + Aplicación Web unificada) en el puerto `3001`.
2. Conectará con la base de datos SQLite local (`database/biblioteca.db`).
3. Abrirá de inmediato la interfaz web en tu navegador (`http://localhost:3001`).

---

## 🛑 Cómo Detener el Sistema

Para apagar el servidor:
- Haz doble clic en **`DETENER_SISTEMA.bat`** (en la raíz del proyecto).
